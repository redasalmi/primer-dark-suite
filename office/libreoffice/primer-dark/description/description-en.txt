An unofficial GitHub Primer Dark-inspired LibreOffice theme. It colors the document and application background, text, links, spelling and grammar marks, Writer, Calc, Draw, and HTML source view markers, tracked-change authors, the Basic IDE and SQL syntax, and the application colors. Select Primer Dark in Tools > Options > LibreOffice > Appearance. Colors are derived from Primer Primitives (MIT); this project is not affiliated with or endorsed by GitHub, Inc.
